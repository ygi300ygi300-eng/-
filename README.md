# READLOG

나만의 독서 기록을 모으는 작고 다정한 웹사이트입니다. 책장, 독서 기록, 통계, 프로필과 연간 독서 목표를 관리할 수 있습니다.

## 실행

Node.js가 설치되어 있다면 프로젝트 폴더에서 실행하세요.

```bash
npm start
```

브라우저에서 `http://localhost:8002`를 여세요. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

## 기능

- 읽고 싶은 책, 읽는 중인 책, 완독한 책 관리
- 페이지 진행률, 독서 날짜, 별점, 감상과 인상 깊은 문장 기록
- 검색, 장르 필터, 정렬과 월별·장르별 통계
- 닉네임과 연간 독서 목표를 보여주는 마이페이지
- 브라우저 `localStorage`에 데이터 저장
- 데스크톱과 모바일 반응형 레이아웃

처음 방문하면 예시 책과 기록이 표시됩니다. 데이터는 현재 브라우저에 저장되며 다른 기기와 자동으로 동기화되지는 않습니다.
